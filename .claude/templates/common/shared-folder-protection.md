# 共有フォルダ・社内フォルダの保護

## ルール概要

| 対象 | 削除 | 書き込み |
|---|---|---|
| `G:\共有ドライブ` / `G:\Shared drives` | hook ハードブロック（bypass 不可） | 確認不要（自由に書き込んでよい） |
| ネットワークドライブ（`\\server\...`）| 行動指示のみ | 確認不要（自由に書き込んでよい） |
| SharePoint / OneDrive | 行動指示のみ | 確認不要（自由に書き込んでよい） |

書き込み（新規作成・上書き・コピー）は都度の確認を取らずに実行してよい（2026-10-07 ユーザー指示）。中身を読まずに既存ファイルを上書きする場合の扱いはローカルと同じ（[security-and-permissions.md](../../spec/security-and-permissions.md)「確認必須操作」）。削除・移動（移動元が消える）は共有データの誤削除を防ぐため行わず、必要な場合はユーザーにエクスプローラから手動で実施してもらう。
