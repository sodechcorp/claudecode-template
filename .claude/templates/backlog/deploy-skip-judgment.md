# デプロイ適否の判定（Phase 1 終了時に適用）

以下のいずれかに該当する場合は、コードのデプロイではなく管理画面の直接操作で対応する:

- （`git check-ignore -q force-app/` が非0終了＝force-app が Git 管理対象内の非標準プロジェクトの場合のみ）`git status` で force-app/ 配下に未コミット差分が 30 ファイル以上ある（デプロイで意図しない設定が上書きされるリスク）。force-app が .gitignore 対象（テンプレート既定の標準構成）の場合、この判定は構造的に適用不可（git status が常に無変更を返すため）
- ページレイアウト等、コード変更なしで管理画面設定変更のみで完結する（プロファイル・権限セットはメタデータ管理が SF 推奨のため、緊急対応を除き本判定の対象外とし、後でメタデータ取り込みを推奨）
- コード変更が不要で Salesforce 管理画面の設定変更だけで完結する（Apex/LWC/Flow の追加・変更なし）
